## 一、后端部署（服务器 <your-server-ip>）

### 1. 建表
在目标 MySQL 库执行 `部署表结构/` 下的 SQL：
- `chat_history.sql` — AI 长对话历史表（新功能必需）
- `travel_schedule.sql` — 行程计划表（若已有可跳过）
- `user.sql` / `script.sql` — 用户与业务表（按需）

> 注意：SQL 中库名写的是 `aitravel.*`，请按服务器实际库名调整（本地开发库是 `geek012`）。

### 2. 配置文件
jar 的数据库/redis 配置在 `application-dev.yml`（已打包进 jar，改 jar 外 `config/application-dev.yml` 或解压修改均可）：
```yaml
sky:
  datasource:
    host: localhost
    port: 3306
    database: <服务器库名>
    username: <用户>
    password: <密码>
```

### 3. 启动
```bash
# 建议使用 nohup 后台运行
nohup java -jar gkv-server-1.0-SNAPSHOT.jar > server.log 2>&1 &
```
验证：`curl http://<服务器IP>:8080/travel/chat` 应返回 JSON（含 code 字段）。

### 4. Agent 服务地址（重要）
新接口会调用 Python AI Agent（`/travel/chat` → `/api/chat`，`/travel/generatePlan` → `/api/plan`）。
配置在 `application.yml`：
```yaml
agent:
  chat-url: http://<your-server-ip>:8002/api/chat
  plan-url: http://<your-server-ip>:8002/api/plan
```
**如果 agent 服务与后端部署在同一台服务器，建议改为 `http://127.0.0.1:8002/...`**，避免公网回环被防火墙拦截（本次联调中公网 IP 8002 端口从本机不可达）。

### 5. 数据库表（chat_history 表结构）
```sql
create table chat_history (
    id          bigint auto_increment primary key,
    session_id  varchar(64)  not null comment '会话ID',
    role        varchar(16)  not null comment '角色：user/assistant',
    content     text         not null comment '消息内容',
    create_time datetime default CURRENT_TIMESTAMP null comment '创建时间'
) comment '聊天历史记录表';
create index idx_session_id on chat_history (session_id);
```

## 二、前端 App 打包（apk）

`dist/build/app/` 是编译产物（API 地址已指向 `http://<your-server-ip>:8080`，`VITE_USE_MOCK=false` 已走真实接口）。

打包 apk 步骤：
1. 用 HBuilderX 打开 `frontend/` 项目（或新建项目后导入 `dist/build/app`）
2. 菜单：发行 → 原生App-云打包
3. 配置包名/证书 → 打包生成 apk/ipa

> 本地若要改 API 地址：编辑 `frontend/.env` 的 `VITE_API_BASE_URL` 后重新 `npm run build:app`。

## 三、新功能接口（本次同步）

| 接口 | 说明 | 请求体 |
|---|---|---|
| `POST /travel/chat` | AI 长对话（多轮记忆，写 chat_history 表） | `{session_id, user_input, base_info{...}, chat_history[]}` |
| `POST /travel/generatePlan` | 长对话后生成完整行程计划（返回 plan_data.day_list） | 同上（带完整 chat_history） |

前端流程：chat.vue 多轮对话 → 点"生成行程计划" → generatePlan → 跳转详情页。
