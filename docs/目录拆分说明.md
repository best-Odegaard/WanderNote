# 项目目录拆分说明（内部记录）

> 本文件记录仓库目录的整理来源，属于项目内部笔记。

本目录由原始开发工作目录拆分整理而来（复制方式，原目录完整保留）。
只包含源代码与配置，已排除 `node_modules/`、`dist/`、`target/`、`__pycache__/`、日志文件、`.git/` 等构建产物和临时文件。整理时间：2026-09-10。

## 各子目录来源对照

| 新目录 | 说明 |
|---|---|
| `backend/` | Java SpringBoot 后端（Maven 多模块：gkv-common / gkv-pojo / gkv-server）。**权威版本**，服务器部署的 jar 即由它构建 |
| `frontend/` | UniApp 用户端（Vue3 + Vite），含 `src/`、`UI设计图/`、`接口文档/` |
| `admin-web/` | 管理端（Vue3 + Vite + TS），仅源码 `src/` 与配置 |
| `travel_self_agent/` | Python AI Agent（FastAPI，端口 8002，提供 /api/chat、/api/plan），含 `rag/`、`knowledge_base/`、`model/`、`config/` |
| `部署表结构/` | 建表 SQL（chat_history / travel_schedule / user / script） |
| `deploy/` | 部署脚本与 Nginx 配置 |
| `docs/` | 项目文档 |

## 未带入本目录的内容及原因

| 原内容 | 原因 |
|---|---|
| 两位开发者的后端过程副本 | 最终代码已合并在根 `backend/` 中 |
| Agent 重复副本 | 与 `travel_self_agent/` 重复 |
| 旧部署产物（jar + sql 快照） | jar 可由 `backend/` 重新构建 |
| 联调/调试临时脚本与依赖 | 非项目正式代码 |
| 联调时的临时配置与请求样例 | 非项目正式代码 |

## 启动速查

- 后端：`cd backend && mvn clean package -DskipTests`，运行 `gkv-server/target/gkv-server-1.0-SNAPSHOT.jar`
- Agent：`cd travel_self_agent && pip install -r requirements.txt && python main.py`（监听 8002）
- 前端 App：`cd frontend && npm install && npm run dev:h5`（App 打包用 HBuilderX 导入）
- 管理端：`cd admin-web && npm install && npm run dev`，Nginx 配置见 `deploy/admin-nginx.conf`

完整启动步骤与环境变量配置见根目录 [README.md](../README.md)。
